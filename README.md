## Chrome Extension

Quick Task Creator - Add tasks to StudySync from any website!

**Download & Install:**
1. Go to [Releases](https://github.com/TAMIM-IQBAL0110/STUDY_SYNC/releases)
2. Download `chrome-extension.zip`
3. Extract the ZIP file
4. Open `chrome://extensions/` in Chrome
5. Enable **Developer mode** (toggle, top right)
6. Click **Load unpacked**
7. Select the extracted folder
8. Done! Use the extension icon in your toolbar
